# PetRx

PetRx is a multi-tenant Veterinary Clinic Management SaaS and Clinical Decision Support Platform (CDSS).

Phase 1 includes:
- Veterinary Clinic Management System
- Client Portal
- Clinic Website Builder
- AI Clinical Evidence Search
- PWA-first deployment

Architecture:
- Organization-Based Multi-Tenant Design
- PostgreSQL + Prisma
- Next.js 16 + TypeScript
- RBAC-first Security Model
